1. Was ist HTML?

HTML steht für "HyperText Markup Language". Es ist eine Auszeichnungssprache für Websites. Sie bestimmt, welche Inhalte auf einer Website stehen und wie sie strukturiert sind.

2. Wofür braucht man HTML?

HTML bildet das Grundgerüst einer Website. Ohne HTML fehlt die grundlegende Struktur für Texte, Bilder und Links.

3. Wie funktioniert HTML?

HTML verwendet sogenannte Tags. Sie markieren beispielsweise Überschriften, Absätze und Bilder. Der Browser liest den HTML-Code und stellt ihn als Website dar.

4. Wie entsteht eine Website?

HTML legt die Struktur fest. CSS gestaltet das Aussehen. JavaScript fügt Interaktionen hinzu. Zusammen ermöglichen sie moderne, dynamische Websites.
